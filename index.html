    Deployment wiring

    How this console maps to AWS
    Bedrock · InvokeModel
    Triage calls go through api.triage(), which posts free text and returns structured JSON: urgency score, categories, summary, suggested matches.
    DynamoDB · reliefpulse-incidents
    Single-table design. PK: INCIDENT#id / SK: METADATA, with VOLUNTEER#id and HAZARD#id partitions and a GSI on status + urgency.
    S3 · reliefpulse-evidence
    Damage photos upload straight from the browser with a presigned PUT; the object key is written back onto the incident item.
    Lambda + API Gateway
    fetchIncidents, createSOS, createOffer, matchVolunteer, resolveIncident — each a handler behind one HTTP route.
    ReliefPulse operates alongside, not instead of, emergency services. · Life-threatening emergencies still go to 911 first. · —
